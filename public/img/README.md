# Panduan Penempatan Foto & Media

Folder ini disiapkan untuk file foto dan media asli kelas XII PPLG 3:

- `public/img/members/` : Foto profil siswa (`001.webp`, `002.webp`, dst.)
- `public/img/gallery/` : Foto galeri kegiatan (`01.webp`, `02.webp`, dst.)
- `public/img/teachers/`: Foto bapak/ibu guru & wali kelas (`01.webp`, dst.)
- `public/img/projects/`: Tangkapan layar proyek & portofolio (`01.webp`, dst.)
- `public/img/memes/`   : Gambar meme kelas (`01.webp`, dst.)
- `public/img/playlist/`: Cover lagu playlist (`01.webp`, dst.)
- `public/img/custom/`  : Hiasan & ornamen kustom tambahanmu

*Catatan:* Jika file foto belum ditaruh di folder ini, sistem secara otomatis menampilkan *Scrapbook SVG Placeholder* bergaya retro aesthetic. Website tetap tampil utuh tanpa error 404 gambar pecah.
